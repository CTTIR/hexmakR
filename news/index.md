# Changelog

## hexmakR 0.2.0

- Add the complete CTTIR v5 library: 45 native R vector identities and
  1,035 unchanged original assets. Named designs place the package name
  inside.
- Add hexagonal, pentagonal and square project logos with
  [`logo_design()`](../reference/logo_design.md); reuse CTTIR motifs or
  any of the 46 generic icons.
- Add a default v5 editor with palette/layout controls, individual shape
  and coordinate editing, highlighting, undo/reset, JSON projects and R
  recipes.
- Add catalogue/asset lookup, editable design objects, layer inspection,
  PNG/SVG/PDF export and complete catalogue regeneration.
- Render name glyphs from the bundled JetBrains Mono font without
  requiring font installation. Preserve transparent exteriors and vector
  geometry.
- Preserve the classic API/designer and record the twelve legacy-only
  names.

## hexmakR 0.1.0

- Initial release
- 19 curated color themes with dark and light variants
- 46 built-in icons across 7 categories (science, biology, data/stats,
  medical, tech/code, shapes, fun)
- Custom image upload support (PNG, JPG, SVG)
- 13 font options with bold/italic toggles
- Interactive Shiny app for visual sticker design
- Programmatic API for scripted/batch sticker creation
- Export to transparent PNG at configurable resolution
- Full roxygen2 documentation and 3 vignettes

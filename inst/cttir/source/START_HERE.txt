CTTIR V5 / SMALL UPLOAD BUNDLES

START WITH CTTIR_Codex_Start_v5.zip.
It contains the full editable R project, bundled fonts, all 45 identities as
SVG/PDF in both compositions (name inside the hex, or artwork only) and all
three modes, plus the offline SVG browser and the main gallery PDF.
All archives are ordinary independent ZIPs under 5,000,000 bytes. This is a
conservative packaging target, not a claim about a documented Codex limit.

Upload the starter alone to work on the design or regenerate everything.
Extract it into a working folder. It creates CTTIR_R_Hex_System_v5/.
Open that folder as the working directory. R with Cairo is required.
The renderer uses only R's bundled packages and locally supplied fonts.
No R runtime is included. Check that Rscript is installed and that
base::capabilities("cairo") returns TRUE.

In a terminal, from CTTIR_R_Hex_System_v5/:
  Rscript render_all.R
  Rscript review_cvd.R
  Rscript validate_exports.R

Or in an interactive R session with that folder as the working directory:
  # Generate the images and galleries from the supplied R geometry.
  base::source("render_all.R")
  # Check the generated exports.
  base::source("validate_exports.R")

OPTIONAL ORIGINAL PNGS AND GALLERIES
The PNG archives contain the original full-resolution PNGs, including icons.
The gallery archives contain the original review sheets and CVD review PDF.
The main gallery PDF is included in the starter.
Extract selected add-ons into the SAME PARENT folder as the starter; their
common project folder merges automatically. Do not nest one project folder
inside another. No binary reassembly or special split-archive tool is needed.
UPLOAD_PARTS.csv maps every PNG package to its archive.
Extract all add-ons to reconstruct every file from the original complete kit.
With only the starter, all SVG previews and the main gallery-PDF link work.
